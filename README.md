# StaySphere | Airbnb-style Project

Full-stack property discovery foundation designed and implemented by Anshu Dayal.

## Run Locally

From the workspace root:

```bash
cd AIRBNB
python -m http.server 8000
```

Open `http://localhost:8000` in your browser.

## Included Features

- Destination search
- Guest-count filtering
- Stay category filtering
- Save/favourite buttons
- Responsive listing grid
- Host onboarding dialog
- Semantic HTML, responsive CSS, and vanilla JavaScript

The current project is a frontend foundation. Authentication, REST APIs, persistence, and MongoDB can be connected as the backend layer is added.
